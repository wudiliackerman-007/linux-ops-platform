# 30 天执行计划

> 这份文档怎么用：每天只做当天一行，做完在 `☐` 里打勾；验收标准不通过就不要进下一天，宁可延一天也不要留坑。时间是按 1.5～3 小时估的，周末可用来补进度。

## 开始前准备

- VMware Workstation 17 已安装，Ubuntu 22.04.5 Server ISO 已下载并校验 SHA256。
- 虚拟机配置 6GB 内存、4 核、60GB 磁盘、NAT 网络；不要一上来就加第二块盘，先把单盘跑通。
- 准备一个仓库外的笔记本，记录每天的实际命令、报错和解决过程；这些就是面试时“遇到过什么”的素材。
- 所有操作都在虚拟机里做，重要节点打快照。快照不是备份，只是方便你搞砸了回滚。

## 四周总览

|---|---|---|---|

## 常见卡点与解决

| 卡点 | 典型现象 | 怎么解决 |
|---|---|---|
| Ubuntu 装不上 | VMware 报 VT-x 不可用、黑屏、卡在安装界面 | 进 BIOS 开虚拟化；确认 ISO 完整；虚拟机至少 4GB 内存；NAT 模式先不要改 |
| apt 源慢或 404 | `apt update` 超时，或提示 Release 文件不存在 | 确认系统是 jammy；换阿里云/清华源；先 `ping mirrors.aliyun.com`；不要混用不同版本的源 |
| SSH 连不上 | `Connection refused` 或 `Permission denied` | 在 VMware 控制台看 `ip -4 addr`；`systemctl status ssh`；`ufw allow 22/tcp`；密钥权限 `chmod 600 ~/.ssh/authorized_keys` |
| sudo 提示不在 sudoers | `ops is not in the sudoers file` | 用 VMware 控制台进 root；`visudo -f /etc/sudoers.d/90-ops-ops`；改完用 `visudo -c` 校验，别直接手改 `/etc/sudoers` |
| MySQL 登录失败 | `Access denied` 或 socket 连不上 | 先 `sudo mysql` 走 socket；检查 `/root/.my.cnf` 权限 600；确认应用账号只从 127.0.0.1 登录；不要在命令行明文写密码 |
| Redis 报 NOAUTH | `NOAUTH Authentication required` | `redis-cli -a '<密码>'`；确认 `requirepass` 和脚本里的密码一致；不要把 6379 开到公网 |
| Grafana 打不开或密码错 | 浏览器连接超时，或 `admin` 登录失败 | `systemctl status grafana-server`；`ss -lntp` 看 3000；`ufw allow 3000/tcp`；忘了密码用 `grafana-cli admin reset-admin-password <新密码>` |
| Prometheus target down | 某个 job 显示 DOWN | 先 `curl 127.0.0.1:<exporter端口>/metrics`；再看 `promtool check config`；最后看 exporter 的 systemd 日志和监听地址 |
| Alertmanager 不发告警 | 规则是 firing，但 webhook 没收到 | `amtool check-config`；`curl` 手动打 webhook；`journalctl -u alarm-receiver -n 50`；检查 silence 和 `group_wait` |
| 端口不通 | 本机 `curl` 通，外面访问不了 | `ss -lntp` 看监听地址；`ufw status`；确认不是只绑了 127.0.0.1；VMware NAT 的 IP 是否变化 |
| 磁盘被演练写满 | `df -h` 100%，服务写日志失败 | 先 `df -h` 和 `du -xhd1 /data` 定位；删 `/data/chaos` 的占位文件；`02_disk_fill.sh --clean`；以后加磁盘告警 |
| 证书浏览器报警 | `NET::ERR_CERT_AUTHORITY_INVALID` | 自签证书本来就会报警；用 `curl -k` 测试；检查 SAN 是否包含你访问的域名/IP；生产要换受信任证书 |
| systemd 服务起不来 | `status=203/EXEC` 或 `status=1` | `systemctl status <服务>` 看退出码；`journalctl -u <服务> -n 100 --no-pager`；检查 `ExecStart` 路径、权限、环境变量和端口占用 |
| 时间不同步 | 日志时间跳、TLS 报错 | `timedatectl`；`systemctl status chrony`；`chronyc sources -v`；NAT 环境确认能访问外网 NTP |

## 最后一句
